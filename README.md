## Alur Git

Kerjakan tugas pada branch masing-masing, lalu buat Pull Request ke `main` untuk direview sebelum merge.

```bash
git checkout main
git pull origin main
git checkout -b nama-branch
git status
git diff
git add file-yang-diubah
git commit -m "ringkasan perubahan"
git push -u origin nama-branch
```

Jangan commit virtual environment, cache, dataset lokal yang tidak dibutuhkan, atau file sementara.
